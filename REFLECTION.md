\# REFLECTION - MID TERM SOFTWARE DEVELOPMENT



\## Refleksi Pembelajaran Minggu 1-7



Selama pembelajaran Software Development, materi yang paling sulit saya kuasai adalah branching, merging, dan penyelesaian merge conflict menggunakan Git. Pada awalnya saya sering bingung membedakan fungsi branch main, development, dan feature branch. Saya juga beberapa kali melakukan commit pada branch yang salah dan mengalami konflik saat merge.



Selain itu, saya juga mengalami kesulitan memahami workflow kolaborasi menggunakan GitHub Projects, Issues, dan Pull Request karena sebelumnya saya hanya menggunakan Git untuk menyimpan file secara sederhana, bukan untuk manajemen proyek perangkat lunak.



Untuk mengatasi hal tersebut, saya mulai berlatih menggunakan branch secara terpisah, melakukan simulasi merge conflict, serta memahami hubungan antara Backend, Frontend, dan Product Lead dalam workflow Agile. Saya juga mulai memahami pentingnya commit message yang jelas, struktur folder MVC, serta dokumentasi seperti API Contract dan Database Schema.



Dari proses ini saya menyadari bahwa Software Development bukan hanya tentang menulis kode, tetapi juga tentang menjaga struktur proyek, komunikasi tim, dokumentasi, dan pengelolaan perubahan secara disiplin menggunakan Git dan GitHub.
